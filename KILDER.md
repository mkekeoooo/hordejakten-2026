# Kilder og rettigheter

Rapportene er satt sammen av Claude på grunnlag av brukerens arbeid og utveksling med Codex. Repositoriets forside og publiseringsnotater er redigert med Codex. AI-genererte tolkninger og beregninger kan inneholde feil.

## Kilder omtalt i rapportene

| Kilde | Rolle |
|---|---|
| [Horde – Hordejakten](https://horde.no/gjeldfri/hordejakten) | Arrangør, konkurranse og regler |
| [YouTube-sendingen](https://www.youtube.com/watch?v=EQHgfmZicc8) | Bilder og tavleutsagn |
| [default.no](https://default.no/) | Åpen logg, klipp, hint og modellarbeid; sekundærkilde for flere observasjoner |
| [Kartverket / Høydedata](https://hoydedata.no/) | DTM og DOM |
| [MET THREDDS](https://thredds.met.no/) | Væranalyse og radar |
| [Dokumentasjon for MET Nordic](https://github.com/metno/NWPdocs/wiki/MET-Nordic-dataset) | Variabler, tidsangivelser og datagrunnlag |
| [OpenStreetMap](https://www.openstreetmap.org/copyright) | Veier, vann og bygninger; © OpenStreetMap-bidragsytere, ODbL |
| [adsb.lol](https://www.adsb.lol/) | Flyspor |
| [Fellesskapskartet](https://github.com/MagnusPladsen/hordejakten-2026) | Delt hint- og kartarbeid |

Rapportene omtaler også Artsdatabanken, Global Forest Watch og nyhetskilder. Enkelte opplysninger er gjengitt via default.no og er ikke originalkontrollert i dette publiseringsarbeidet. Dette er et datert arkiv, ikke en automatisk oppdatert gjengivelse av kildene.

## Videre bruk

Ingen samlet lisens er lagt på dette materialet. At repositoriet er offentlig betyr ikke at skjermbilder, kartgrunnlag og andre tredjepartsbidrag er fritt lisensiert. Opphavsrett og kildevilkår gjelder fortsatt for hvert element. Oppgi kilde og behold figurtekst, dato og forbehold ved henvisninger.
